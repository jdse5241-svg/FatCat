# FatCat
一只住在你桌面上的小猫，搭配独特鼠标光标皮肤

## 特色
- 桌面宠物，会跟随和回应你的鼠标
- 配套的猫爪光标皮肤：普通、悬停、按下、忙碌、文本输入
- 抚摸互动与动作表现经过调整
- 绿色免安装，目前支持 Windows x64

## 下载与使用
1. 点击本页右侧的"发布"，下载 `FatCat-Windows-x64-Portable.zip`
2. 解压后双击 `FatCat.exe`
3. 如果旧版仍在运行，请先从托盘菜单退出旧版

## 常见问题
**Windows 提示"未知发布者"或杀毒软件报警？**
程序没有购买数字签名，所以会出现提示。选择"更多信息"，再点"仍要运行"即可。
你也可以按下面的方法自行编译。

**怎么退出？**
右键托盘区的图标，选择退出。

## 自行编译
需要安装 MSVC C++ 工具和 Windows SDK。
打开 x64 Native Tools 命令提示符，进入源码根目录，运行：

    windows\build.bat

构建成功后运行 `windows\FatCat.exe`。
