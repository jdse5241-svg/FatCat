### 🐾 互动
- 键盘和鼠标的动作会同步到小猫的手脚上
- 鼠标划过猫身会触发互动，闲置久了小猫还会打瞌睡
- 透明区域不挡操作，不影响你正常使用电脑

### 🎨 皮肤规划
- ✅ 经典小黑猫（已完成，含五种光标形态）
- 🚧 更多猫咪皮肤与同款光标（设计中，敬请期待）

## 📦 下载与运行
支持 Windows 10 / 11（x64）。

1. 点击页面右侧的"发布"，下载 `FatCat-Windows-x64-Portable.zip`
2. 解压后双击 `FatCat.exe`，无需安装
3. 如果旧版仍在运行，请先从右下角托盘菜单退出旧版
4. 右键托盘里的小猫图标，可以调整外观、尺寸、开机自启等选项

> 若部分游戏无法响应，请右键 `FatCat.exe`，选择"以管理员身份运行"。

### ❓ 常见问题
**Windows 提示"未知发布者"，或杀毒软件报警？**
程序没有购买数字签名，所以会出现提示。点"更多信息"，再点"仍要运行"即可。你也可以阅读源码，自行编译。

**怎么退出？**
右键托盘区的图标，选择退出。

## 自行编译
需要安装 MSVC C++ 工具和 Windows SDK。
打开 x64 Native Tools 命令提示符，进入源码根目录，运行：

    windows\build.bat

构建成功后运行 `windows\FatCat.exe`。
